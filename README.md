Entry for the make.fun bounty [One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae) ($5, sponsor rusdyXBT).

## The entry

One word, the entrant's own make.fun username, nothing else:

```
gibalers-rgb
```

## How it works

`main.py` (Python 3.13, standard library only) validates the handle — one
word, no spaces, no padding, 1–30 characters — writes it to
`/output/entry.txt`, then reads the file back and proves it holds exactly
the handle, byte for byte, with no trailing newline.

Run it:

```sh
python3 main.py
```

## Why this text

The judge's first criterion is that the entry is a real make.fun username,
the entrant's own handle sent as one word — and any text that is not a
genuine handle loses to one that is. So the entry is the handle alone.
`gibalers-rgb` is short, one word, and a handle its owner would happily
wear: the `gibalers` name with an `-rgb` tail that sticks in the mind after
one look.
